# 无缝渐变玻璃 (Seamless Gradient Glass)



一个适用于 Minecraft Java 1.19.4 以上的 Fabric 客户端模组。它能让相邻的玻璃连成一整面透明玻璃墙——只保留外缘细框和玻璃表面的斜向反光，颜色则会顺着相邻方块在水平和竖直方向上自然渐变。每次放置或敲掉玻璃都会实时刷新渲染。



## 安装与上手



* **运行环境**：先空着（待补充）

* **安装方式**：仅需客户端安装，单人存档与多人服务器均可直接生效。



## 核心特性



### 玻璃与透明方块联动

* **全系玻璃支持**：普通玻璃、16 色染色玻璃，以及它们对应的玻璃板都能参与横竖双向渐变。默认材质下，普通玻璃的中心区域会更通透，同时保留边缘高光与斜纹反光。

* **玻璃板细节**：按原版逻辑自动连接成细柱、直墙、转角、丁字或十字路口，上下叠放时也只会露出最外层的薄边。

* **遮光玻璃与信标**：遮光玻璃会带着原本的深灰紫色融入相邻玻璃的渐变中（依然保持原版遮光特性）。信标的玻璃外壳同样可以和普通玻璃、染色玻璃、遮光玻璃乃至相邻信标无缝相连，内部晶体、黑曜石底座和光束渲染则保持原样。



### 材质包与光影生态兼容

* **CTM 连接纹理材质包**：重载资源包时，模组会自动扫描已启用材质包里的 `optifine/ctm/**/*.properties`。支持常见的 `ctm_compact`（5 图）和标准 `ctm`（47 图）静态规则（支持 `matchBlocks` / `matchTiles` 匹配及 `tiles` 编号/文件列表），默认以白色玻璃作为染色基底；如果玻璃板没写单独规则，会自动复用整块玻璃的贴图。

  - **注意**：如果想优先用某个材质包的玻璃样式，请把它拉到资源包列表最上方（同包内按路径顺序匹配）。带生物群系、高度、方块状态条件的规则，以及随机/覆盖层规则暂未支持；未匹配到规则时会自动回退到模组自带的渐变贴图。

* **Continuity 兼容**：可以直接与 Continuity 同装，同时开启它内置的 `Default` 和 `Glass Pane Culling Fix` 资源包即可。本模组接管各类玻璃与玻璃板的渲染，其他方块依然走 Continuity 的连接纹理。



### 信标光束平滑过渡

激活的信标光束穿过不同染色玻璃时，不再是生硬的分段变色，而是在一格高度内从上一层的颜色平滑过渡到下一层（光束中心与外层光晕同步渐变，顶部维持最终混合色）。如果同时装了 Sodium Extra 0.7.0，模组会自动关闭其冲突的信标光束渲染优化，保证渐变正常显示。



## 性能实测



针对大面积玻璃墙做了网格合并：整块玻璃沿用 3×3 颜色采样，只要某一轴向上的三组采样 ARGB 完全一致且处于同一贴图层，就会直接合并网格，大幅减少冗余面数。同时，整块玻璃与玻璃板共享单次资源重载的贴图缓存，构建线程各自复用采样缓冲以降低内存开销。



经实测，在大面积同色玻璃的场景下未出现明显的性能问题，详细测试数据与对比截图见 [benchmarks/0.5.1](benchmarks/0.5.1)。
